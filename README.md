# ia-mentor-de-carreira-dio
🧠 MAPA DE SKILLS (atualizado)

CORE SKILLS (essenciais):

Lógica de programação (Python)

SQL para consultas em bancos de dados

Estatística básica e análise exploratória

Versionamento de código com Git/GitHub

NICE-TO-HAVE (complementares):

Visualização de dados (Power BI, Tableau)

Noções de Machine Learning

FERRAMENTAS E TECNOLOGIAS:

Python (pandas, numpy, matplotlib)

SQL (MySQL, PostgreSQL)

Power BI

GitHub

📅 ROADMAP DE 90 DIAS (com GitHub)

MÊS 1 - FUNDAMENTOS  
SEMANA 1-2:

Aprender lógica de programação com Python

Instalar ambiente (Jupyter Notebook, VS Code)

Criar conta no GitHub e aprender comandos básicos do Git (commit, push, pull)

SEMANA 3-4:

Introdução a bancos de dados e SQL

Praticar consultas simples (SELECT, WHERE, JOIN)

Publicar seu primeiro repositório com exercícios de Python e SQL

MÊS 2 - PRÁTICA  
SEMANA 5-6:

Manipulação de dados com pandas

Estatística básica (média, mediana, desvio padrão)

Organizar notebooks no GitHub com README explicando cada análise

SEMANA 7-8:

Visualização de dados com matplotlib e seaborn

Criar pequenos relatórios exploratórios

Aprender a usar branches e pull requests no GitHub

MÊS 3 - PORTFÓLIO E PREPARAÇÃO  
SEMANA 9-10:

Construir dashboard no Power BI com dados públicos

Documentar processo de análise

Publicar o projeto completo no GitHub com README detalhado e imagens do dashboard

SEMANA 11-12:

Simular entrevistas técnicas

Revisar conceitos principais e preparar portfólio

Deixar o GitHub organizado com repositórios bem documentados e fixar o projeto principal no perfil
